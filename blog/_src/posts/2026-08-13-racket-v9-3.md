We are pleased to announce Racket v9.3 is now available from [https://download.racket-lang.org/](https://download.racket-lang.org).

## As of this release:

* The [`raco setup`](https://docs.racket-lang.org/raco/running.html) command can generate markdown documentation, using the `--doc-markdown` option.
* The "#lang" [teaching languages](https://docs.racket-lang.org/htdp-langs/index.html) (BSL, ..., ISL+; plus DeinProgram) have reached parity with the ones chosen using the Language dialog, and are the recommended choice.
* DrRacket's background expansion disables errortrace annotations, for faster [syntax checking](https://docs.racket-lang.org/drracket/buttons.html#%28idx._%28gentag._8._%28lib._scribblings%2Fdrracket%2Fdrracket..scrbl%29%29%29).
* The [`raco pkg install`](https://docs.racket-lang.org/pkg/cmdline.html#%28part._raco-pkg-install%29) command includes new options that provide more install-time configuration flexibility: `--adjacent-deps`, `--destdir`, and `--attach`, and a refined `--skip-installed`.
* The `ffi/unsafe/runtime-lib` library provides a [`define-runtime-lib`](https://docs.racket-lang.org/foreign/runtime-lib.html#%28form._%28%28lib._ffi%2Funsafe%2Fruntime-lib..rkt%29._define-runtime-lib%29%29)  mechanism similar to `define-runtime-path`, allowing location of libraries located relative to a source file.
* The [`prompt-tag/c`](https://docs.racket-lang.org/reference/data-structure-contracts.html#%28form._%28%28lib._racket%2Fcontract%2Fprivate%2Fmisc..rkt%29._prompt-tag%2Fc%29%29) contract generator no longer performs checking on `call/cc` when the `#:call/cc` option is not present.
* The [`impersonate-prompt-tag`](https://docs.racket-lang.org/reference/chaperones.html#%28def._%28%28quote._~23~25kernel%29._impersonate-prompt-tag%29%29) function takes an additional argument that allows checking and update of results for composable continuations.
* The [`error-syntax->srcloc-handler`](https://docs.racket-lang.org/reference/exns.html#%28def._%28%28quote._~23~25kernel%29._error-syntax-~3esrcloc-handler%29%29) parameter provides control over the mapping from syntactic forms to source locations for error handling.
* Uses of `([tcp-listen](https://docs.racket-lang.org/reference/tcp.html#%28def._%28%28lib._racket%2Ftcp..rkt%29._tcp-listen%29%29) 0)` will retry when it fails with "address in use".
* The [`racket/base`](https://docs.racket-lang.org/reference/index.html) module requires fewer internal modules and instantiations.
* The `file/zip` package provides a [new mechanism](https://docs.racket-lang.org/file/zip.html#%28def._%28%28lib._file%2Fzip..rkt%29._zip-entry~3f%29%29) for greatly increased control over zip file generation, allowing in-memory file sources and per-file compression control.
