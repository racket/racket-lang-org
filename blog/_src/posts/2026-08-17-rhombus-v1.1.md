Rhombus version 1.1 is now available!

We are pleased to announce Rhombus 1.1 is now available from https://rhombus-lang.org

*[Rhombus](https://rhombus-lang.org/) is a general-purpose programming language that is easy to use and uniquely customizable.*

## As of this release:

* Add [`annot`](https://docs.racket-lang.org/rhombus-reference/Annotations.html?fam=Rhombus&famroot=rhombus#%28def._%28%28submod._%28lib._rhombus%2Fprivate%2Famalgam..rkt%29._core%29._annot._rhombus%2Fdefn%29%29) and [`annot.def`](https://docs.racket-lang.org/rhombus-meta/Annotation_Macros.html?fam=Rhombus&famroot=rhombus#%28def._%28%28submod._%28lib._rhombus%2Fprivate%2Famalgam..rkt%29._core-meta%29._annot._%28annot..def._rhombus%2Fdefn%29%29%29) as ways to define an annotation without
  directly writing meta-time (i.e., macro) code.

* Add [`as`](https://docs.racket-lang.org/rhombus-reference/Definitions.html?fam=Rhombus&famroot=rhombus#%28def._%28%28submod._%28lib._rhombus%2Fprivate%2Famalgam..rkt%29._core%29._as._rhombus%2Fbind%29%29) as a binding form, which is sometimes more readable for
  naming than using `&&` and provides a way to shadow an identifier
  that is bound as a binding form.

* Change [`class`](https://docs.racket-lang.org/rhombus-reference/class.html?fam=Rhombus&famroot=rhombus) to bind inherited names using the corresponding
  superclass or interface reference.

* Change [`space.enforest`](https://docs.racket-lang.org/rhombus-meta/ref-space.html?fam=Rhombus&famroot=rhombus#%28def._%28%28submod._%28lib._rhombus%2Fprivate%2Famalgam..rkt%29._core-meta%29._space._%28space..enforest._rhombus%2Fdecl%29%29%29) to adjust scopes in the same way as for a
  macro transformer when applying an identifier handler.

* ffi: Add an initialized-array variant of [`new`](https://docs.racket-lang.org/rhombus-ffi/pointer.html?fam=Rhombus&famroot=rhombus#%28def._%28%28lib._ffi%2Fmain..rhm%29._new%29%29).

* [pict](https://docs.racket-lang.org/rhombus-pict/index.html?fam=Rhombus&famroot=rhombus): Change `explain_anim` to add a `~label_as` argument. Change
  `Pict.rebuilt` to replace as rebuilt, and also add a `~as_rebuilt`
  argument to select the old or new bevavior. The `Pict.rebuild`
  method also supports `~as_rebuilt`. Improve `magic_move` and
  `cross_fade` to better handle paragraph points and multiple
  instances of a child pict.

* [slideshow](https://docs.racket-lang.org/rhombus-slideshow/index.html?fam=Rhombus&famroot=rhombus): Add `slide_transition` and `continued` page numbering.

Thank you to community members who contributed this release.
